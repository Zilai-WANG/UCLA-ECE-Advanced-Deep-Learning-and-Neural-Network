This repository contains code implementations, projects, and assignments for **Advanced Deep Learning** at UCLA. The focus of this work is on modern Generative AI architectures and Reinforcement Learning strategies.

## 📚 Topics Covered

This repository explores advanced paradigms in deep learning with a focus on generative modeling and decision making:

### 1. Generative Models
* **Diffusion Models:** Implementation of Denoising Diffusion Probabilistic Models (DDPM), score-based generative modeling, and image synthesis.
* **Variational Autoencoders (VAEs):** Latent variable modeling, Reparameterization trick, and ELBO optimization.
* **Generative Adversarial Networks (GANs):** Minimax game theory, DCGANs, Wasserstein GANs (WGAN), and mode collapse mitigation.

### 2. Reinforcement Learning (RL)
* **Value-Based Methods:** Q-Learning and Deep Q-Networks (DQN).
* **Policy-Based Methods:** Policy Gradients and Actor-Critic architectures.
* **Advanced RL:** Proximal Policy Optimization (PPO) and model-based RL.
